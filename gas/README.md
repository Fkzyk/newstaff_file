# 新店把握シート 自動入力の設定手順

「新店情報シート貼付」に新店情報シートを貼り付けると、
「新店（情報）フロー」の該当店舗の行に自動で情報が入ります。

## 自動で入る項目

| フロー一覧の列 | 入る内容 | 取得元 |
|---|---|---|
| 所属コード・所属名 | 店番・店名 | 貼付フォームの「店番・店名」 |
| 営業部・営業部長 | 例: 関東第三・貴島 遼介 | 「営業部」シートを店番・店名で照合 |
| 都道府県・市町村 | 例: 神奈川県・横浜市 | 貼付フォームの「住所」を自動分割 |
| 引渡日 | 例: 2026/09/18 | 貼付フォームの「引渡予定日」 |
| グランドOP | 例: 2026/10/08 | 貼付フォームの「グランドOP」 |
| 店舗電話番号 | 例: 045-922-5461 | 貼付フォームの「電話番号」 |
| 店舗住所 | 住所そのまま | 貼付フォームの「住所」 |
| 担当者電話番号 | 例: 070-3182-7447 | **面接担当者(T列)を入力すると「連絡先」シートから自動で入る** |

- 同じ店番の行がすでにあれば**その行を更新**します。店番がまだ無い新店は
  **店名で照合**するので、貼り直しても行が二重にできません。
  どちらも見つからなければ一番下に新しい行を追加します。
- フォームを貼り直したときは、フォームの内容をそのまま写します
  （フォームで空欄の項目はフロー側も空欄に戻り、前の店の古い値が残りません）。
- 手で入れる列（時給調査依頼〜追加採用の日程、面接会場、面接担当者）には**触りません**。
- **面接担当者（T列）に名前を入れると、隣の担当者電話番号（U列）が
  「連絡先」シートから自動で入ります**。
  - 「長屋（1週間）→石井」のように複数名やカッコ書きがあっても大丈夫です
    （複数名のときは「長屋090-…、石井070-…」の形で入ります）
  - 同じ名字の人が複数いて特定できないときは入力せず、お知らせで教えます
    （そのときはフルネームで入れ直すか、手でU列に入力してください）
  - 既存の行をまとめて埋めたいときは、メニュー
    **新店フロー → 面接担当者の電話番号を一括入力** を押してください
    （U列が空欄の行だけ埋めるので、手で入れた番号は消えません）
- 反映されるたびに**画面右下に小さなお知らせ**が出ます
  （「既存の行を更新しました: 341 横浜霧ケ丘(8行目)」など）。
  エラーが起きたときも同じ場所に表示されます。

## 設定手順（最初の1回だけ・5分）

1. 新店把握シートを開く
2. 上のメニューから **拡張機能 → Apps Script** をクリック
3. 開いた画面の左側で「コード.gs」を選び、中身をすべて消す
4. `new_store_flow.gs` の中身をすべてコピーして貼り付ける
5. 上の **保存マーク（フロッピー）** を押す
6. 上の関数選択メニューで **syncNewStore** を選び、**実行** を押す
7. 「承認が必要です」と出たら:
   1. 「権限を確認」→ 自分のGoogleアカウントを選ぶ
   2. 「このアプリはGoogleで確認されていません」と出たら
      「詳細」→「（プロジェクト名）に移動」をクリック
   3. 「許可」を押す
8. これで完了。以降は貼り付けるだけで自動的に入ります

## 使い方

1. 「新店情報シート貼付」シートに、届いた新店情報シートを貼り付ける
2. 数秒待つと「新店（情報）フロー」に自動で行が入る（または更新される）
3. うまく入らなかったときは、上のメニュー **新店フロー → 貼付フォームを今すぐ取り込む** を押す
   （このメニューはシートを開き直すと表示されます）

## 注意

- 営業部・営業部長は「営業部」シートに店名（または店番）がある場合に入ります。
  見つからないときは空欄のまま＋お知らせに「※営業部が見つからず空欄です」と
  出るので、手で入力してください。
  （店名の「が/ケ」の違い、例: 霧が丘/霧ケ丘 は自動で吸収します）
- 手で直した営業部・営業部長・都道府県・市町村は、自動処理では消しません。
- 貼付フォームの形（店番・店名がC4、住所がH4など）が変わると読めなくなります。
  形を変えたときは担当者に相談してください。
