# 入社書類作成アプリ

新入社員一覧のスプレッドシートを読み込み、一人ひとりに合わせた入社書類一式と
メール下書きを一括で作成するアプリです。

## 作成される書類

| 書類 | 差し込まれる内容 |
|---|---|
| 入社のご案内 | 宛名、入社式の日時・場所、宿泊先、研修〜店舗配属の日程 |
| 雇用契約書 | 氏名、入社日、就業場所(配属店舗)、役職、等級、給与(給与テーブルから自動計算) |
| 入社辞令 | 原本の.doc(金の飾り枠・毛筆書体)の氏名・ふりがな・日付だけを差し替え |
| 社宅利用申込のご案内 + 入力マニュアル | ※スプレッドシートの「転居」列が「〇」の方にのみ添付 |

各書類は **Word/Excel(編集用)と PDF(送付用)の両方**が保存され、
宛先・件名・本文・PDF添付まで入った **メール下書き(.eml)** も作成されます。

## 使い方(普段は3ステップ)

1. デスクトップの「**入社書類アプリ**」アイコンをダブルクリック
   (初回だけフォルダ内の `start.bat` をダブルクリック。アイコンは自動で作られます)
2. ブラウザが開き、新入社員一覧が**自動で読み込まれます**。
   等級・月給チェックも毎回自動で実行され、結果が画面に表示されます。
   作成対象(これから入社する方)には自動でチェックが付いています。
3. 「**🚀 ◯名分を作成する**」ボタンを押す
   → デスクトップの「**入社書類**」フォルダに `入社日` → `氏名` で一式が保存されます。
   各フォルダの `メール下書き.eml` をダブルクリックすると、宛先・件名・本文・
   添付入りの下書きがメールソフトで開くので、確認して送信するだけです。

- 入社日が過ぎた方・シートでグレーアウトされた方は自動でスキップされます
- 社宅案内は「転居」列が〇の方に自動で付きます(画面で変更も可能)
- **ジョブカン案内メール**も画面のボタンで作成できます
  (宛先=人事3名、BCC=同じ入社日の新入社員全員が自動設定。
  日付記入とPDF添付だけ送信前に手動で行う運用です)
- シートの自動読み込みに失敗したときは、画面の案内に従って
  xlsxをドラッグ&ドロップすれば同じように使えます

## 間違いを見つけたとき(修正の反映)

1. 出力フォルダ内の **Word / Excel を直接修正**して保存
2. アプリの「6️⃣ 内容を修正したいとき」で対象者を選び
   「♻️ この方のPDFとメール下書きを作り直す」を押す

PDFとメール下書きだけが作り直され、手で直した Word/Excel はそのまま残ります。
(全員の日付が違う等、元データの問題の場合はスプレッドシートを直して再作成してください)

## 必要な環境

- **Python 3.10以上** … https://www.python.org/downloads/
  (インストール時に「Add python.exe to PATH」へ必ずチェック)
- **PDF変換ソフト** … 次のどちらかがあれば動きます
  - Microsoft Office (Word / Excel) ※インストール済みならそのまま使われます(再現度最優先)
  - LibreOffice … https://ja.libreoffice.org/
- 辞令の毛筆フォント「HG正楷書体-PRO」はOffice付属のフォントです。
  無いPCでは標準の明朝体で出力されます。

## スプレッドシートの前提

- 1枚目のシートの **2行目がヘッダー、3行目以降がデータ**
- 使用する列: ふりがな / 氏名 / 所属名 / 役職 / 等級 / 入社日 / メールアドレス /
  トレセン研修開始日 / トレセン研修終了日 / 公休(2列) / 店舗配属日 /
  初日勤務開始時間 / 転居
- 入社日が「07/06」のように年なしの場合は、画面の「入社日の年」が使われます

## フォルダ構成(開発者向け)

```
app.py                  操作画面(Streamlit)
generator/
  data.py               スプレッドシートの読み込み・正規化
  documents.py          書類の生成とPDF変換
  emails.py             .emlメール下書きの作成
  pipeline.py           一人分の一括生成・再変換
  defaults.py           既定値(会社情報・メール文面・日付整形)
templates/              差し込み用テンプレート(Word/Excel/PDF)
tools/build_templates.py  元ファイルからテンプレートを再作成するスクリプト
```
